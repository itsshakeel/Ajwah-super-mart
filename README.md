# Ajwah Super Mart — Demo Website

A premium, fully responsive demo website for **Ajwah Super Mart**, built by **AKCLNT**.

## ✨ What's inside

- **Hero section** with store imagery, floating feature cards & call-to-action buttons
- **6 category cards** — Fresh Produce, Dairy & Eggs, Bakery, Beverages, Snacks & Pantry, Household Essentials
- **Featured products grid** — 12 products with live search + category filters
- **Working basket (cart)** — add items, change quantities, then send the whole order to WhatsApp in one tap
- **Services, 3-step ordering guide, visit-us section & footer**
